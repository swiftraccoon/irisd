# Protocol documents (local copies)

The IETF documents the record and serving paths implement, kept verbatim so that reviews
and design discussions cite local text. The engineering standards (Rust style, API
guidelines, Google's Rust and documentation guidance, Conventional Commits, Semantic
Versioning) live in the reference pack under `.rust-reference/`; `STANDARDS.md` at the
repository root is the digest of what irisd adopts from all of them.

| Directory | Documents | License |
|---|---|---|
| `ietf/` | RFC 2326 (RTSP 1.0), RFC 3550 (RTP), RFC 7798 (HEVC RTP payload), RFC 8216 (HLS) and draft-pantos-hls-rfc8216bis-22, RFC 6381 (codecs parameter) | IETF Trust |

The files are the published text from `https://www.rfc-editor.org/rfc/rfcNNNN.txt` and
`https://www.ietf.org/archive/id/draft-pantos-hls-rfc8216bis-22.txt`; a published RFC does
not change, so there is nothing to refresh. Do not edit them.
